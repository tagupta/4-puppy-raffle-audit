# About

> This protocol enables users to enter raffle with some entrance fee. Duplicates are not allowed to enter the raffle.
> It enables users to go for refunds before the winner is announced.
> Only the owner of the contract can set the feeAddress, address where all the 20% of the all the fees is moved.

## High

1. Found a DOS with the for loop of `PuppyRaffle::enterRaffle`.
2. Found a DOS if 2 or more addresses ask for refund
3. Found a Reentrancy attack - A user can claim entracefee mutiple times.
4. Found a discrepancy in the amount distribution. May try to distribute more than the contract has.
5. Found that the winner might come around as address(0)
6. DOS if someone's got refund or added money into the contract using some mailcious method.

## Informational

`PuppyRaffle::entranceFee` is immutable so it should be like `PuppyRaffle::i_entranceFee`
